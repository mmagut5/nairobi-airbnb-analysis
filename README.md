# Nairobi Airbnb Market Analysis

## 1. Project Overview

This project explores the Airbnb short-term rental market in Nairobi, Kenya, using data analytics and business intelligence tools.

The aim is to examine listing distribution, pricing patterns, neighbourhood characteristics and accommodation types to understand the Nairobi Airbnb market.

The project uses Python for data cleaning and exploratory data analysis, alongside Power BI for interactive data visualisation and reporting.

## 2. Business Objectives

The analysis aims to answer the following questions:

- How are Airbnb listings distributed across Nairobi neighbourhoods?
- Which neighbourhoods have the highest number of active listings?
- How do listing prices vary across neighbourhoods?
- Which accommodation types are most common?
- What patterns can be identified in listing availability?
- What insights can help Airbnb hosts and property investors understand the market?

## 4. Dataset

The project uses Airbnb listing data for Nairobi.

The dataset contains information about active listings and neighbourhood-level characteristics.

**Files included:**

- `listings_active.csv` – Airbnb listing-level data.
- `neighbourhood_summary.csv` – Aggregated neighbourhood-level data.


## 5. Project Methodology

### Data Cleaning and Preparation

- Imported and inspected the dataset using Python.
- Examined missing values and duplicate records.
- Reviewed data types and relevant variables.
- Prepared the dataset for exploratory analysis.
- Generated neighbourhood-level summary data.

### Exploratory Data Analysis

Investigated:

- Listing distribution by neighbourhood.
- Price distribution and variations.
- Room and accommodation types.
- Listing availability.
- Neighbourhood-level patterns.

### Data Visualisation

Used Python to explore relationships and communicate patterns through charts and statistical visualisations.

### Business Intelligence

Developed a Power BI dashboard to present key market indicators, neighbourhood comparisons and Airbnb listing characteristics.

## 6. Key Findings

The analysis focuses on identifying:

- Neighbourhoods with the highest concentration of Airbnb listings.
- Differences in advertised prices across neighbourhoods.
- The most common accommodation types.
- Patterns in listing availability.
- Potential areas of interest for hosts and property investors.

## 8. Business Insights and Applications

The findings can support:

- **Property investors:** Understanding listing concentration and neighbourhood-level market patterns.
- **Airbnb hosts:** Exploring competition and advertised pricing across neighbourhoods.
- **Property managers:** Understanding accommodation trends and listing characteristics.
- **Business analysts:** Using data to support market research and business decisions.

## 9. Project Limitations

- The analysis is based on the available Airbnb listing dataset.
- Advertised prices may differ from actual booking prices.
- Listing availability does not necessarily represent actual occupancy.
- The analysis is exploratory and does not establish causal relationships.
- Investment opportunities cannot be determined from listing data alone.

## 10. Future Improvements

- Incorporate historical listing data to analyse market trends.
- Develop predictive models for Airbnb pricing.
- Integrate additional property market and economic indicators.
- Explore factors influencing listing prices.
- Incorporate occupancy and booking data where available.
